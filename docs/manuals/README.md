# Manuals

Copy the PDFs here (they are large; keep them out of `CLAUDE.md` imports and search them with
`pdftotext -layout <file>.pdf - | grep -n <term>` or read specific page ranges):

- `VeloxRemoteInterfaceGuide.pdf`: SCI/GPIB interface, Kernel and chuck commands, error codes.
- `VeloxUserGuide.pdf`, `VeloxProUserGuide.pdf`, `VeloxQuickStartGuide.pdf`.
- `HP_34401A_Users_Manual.pdf`: SCPI commands, RS-232 configuration, specifications.
- The ADG729 datasheet (Analog Devices), to settle the switch-bit mapping.

The first four are in the claude.ai Project "SPT-3G+ probe station"; the 34401A manual was uploaded in the chat.
